# Modelos das armas

Modelos 3D **CC0 (domínio público)** do pacote Flat Guns, de PCL:
- Flat Guns West: https://opengameart.org/content/cc0-flat-guns-west
- Flat Guns East: https://opengameart.org/content/cc0-flat-guns-east

Baixados do espelho em https://github.com/petroulacl/fps-asset-kit.

| Arquivo | Arma no jogo |
|---|---|
| Pistol_Full_West.glb | Pistola |
| Pistol_Full_East.glb | Deagle (pintada de cromado no jogo) |
| SMG_Full_West.glb | Submetralhadora |
| Shotgun_Pump_East.glb | Shotgun |
| Rifle_Assault_East.glb | Metralhadora |
| Rifle_Battle_West.glb | Rifle semiautomático |
| Sniper_Rifle_West.glb | Sniper (a luneta é montada no jogo) |

O jogo separa as peças pelo esqueleto do GLB (ferrolho, carregador, telha da shotgun) para animar tiro e recarga.
Se o modelo não carregar (sem internet para o leitor de GLB), a arma antiga feita de caixas aparece no lugar.
Dá para desligar em Configurações > Vídeo > "Armas detalhadas".
